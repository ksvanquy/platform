# Admin Web

Ứng dụng quản trị (Portal Quản lý Đề thi, Ngân hàng câu hỏi, Giám thị và Thống kê kết quả thi).

## Nhiệm vụ
- Quản lý ngân hàng câu hỏi và chính sách chấm điểm (Scoring Policies).
- Cấu hình đợt thi, mã đề thi, thời lượng làm bài.
- Theo dõi tiến trình thí sinh và báo cáo kết quả tổng hợp.
